# 쏘카 웹 · 차종 리스트 보장상품 배너 상태값 프로토타입

쏘카 웹(모바일 웹 · PC) 차종 리스트의 보장영역(보장상품·혜택) 배너 상태값을
피그마 "쏘카웹" 섹션 그대로 구현한 인터랙티브 프로토타입입니다. 앱 버전과 같은 배너 정책을 적용했어요.

- `index.html` 한 파일로 동작합니다 (이미지·아이콘·폰트 모두 내장, 외부 의존성 없음).
- 화면: 모바일 웹(지도 + 바텀시트 half로 진입 → 시트를 올리면 리스트 페이지로 전환, "지도에서 찾기"로 복귀) / PC 웹(왼쪽 리스트 + 지도)
- 상태값: 지역(내륙/제주) × 지난 예약 보장상품(완전보장 기본값/실속보장) × 바텀시트(half 기본 · 펼침 = 리스트 페이지) × 진입(최초 진입/1회 확인 유저) × 문구(기본/긴 문구 줄바꿈 확인)
- 배너: "보장은 포함, 혜택은 추가로 받아요" — 앱과 같은 컴포넌트. 미확인 유저에게만 1회 자동 펼침, 그 뒤에는 58px 2줄 요약으로 접힘. half에서 배너를 누르면 시트 높이는 그대로 두고 배너만 펼침
- 1회 확인 유저: 모바일 웹은 ① 시트를 올려(리스트 페이지) 차량 리스트를 1회 이상 확인 ② 배너를 클릭/누름 · PC는 ① 첫 방문(리스트가 바로 보여 1회 자동 펼침) ② 배너를 클릭/누름 — PC 기준은 피그마 메모상 논의 중이라 프로토타입 가정
- 특약: 블랙라벨 차량의 "OO 대신 특약 적용 ⓘ" 칩 → 웹은 바텀시트 대신 가운데 모달로 안내
- 인터랙션: 시트 핸들(탭·드래그), 지도에서 찾기, 배너 접기/펼치기, 특약 모달, As-Is(현재 쏘카 웹) 비교 보기
- 피그마 원본: https://www.figma.com/design/qx25HScQEfYlTPslaZTsLP/?node-id=13405-325540
- 앱 버전 프로토타입: https://socar-bora.github.io/coverage-banner-prototype/
